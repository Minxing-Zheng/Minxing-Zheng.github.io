About this collection

This explorer brings together the publicly displayed results from Interactive Visualization and Representation Analysis Applied to Glacier Segmentation, by Minxing Zheng, Xinran Miao, and Kris Sankaran.

147 patchesInput, reference, prediction, and displayed accuracy recovered from the original interactive app.
A clearer visual languageThe Glacier palette recolors the saved masks while preserving class assignments. Cyan: clean ice. Sand: debris-covered. Choose Original paper to see the archived colors.
Geographic contextPatch coordinates are read from the original app’s map popups. Glacier outlines come from the project’s archived vector data.
Visual difference layerComputed from the displayed masks for inspection. It does not replace the original model’s pixel accuracy or provide new IoU estimates.

This is a 2026 reconstruction of the original interactive results. Reported accuracy is copied at the precision displayed by the original app. Patch imagery is preprocessed model input and may differ from natural-color satellite basemaps. The map is geographic context; patch images are not georeferenced overlays.

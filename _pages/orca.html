Minxing Zheng · Shixiang Zhu

Accepted to NeurIPS 2026

ORCA: Optimized Ranking and Coverage Allocation. Generated samples are ranked by a local density proxy. ORCA allocates different radii across those ranks, then calibrates their common scale for finite-sample marginal coverage.

Why allocate coverage?

PCP places equal-radius balls around generated samples. A single radius can spend substantial volume on rare, diffuse regions. ORCA learns rank-specific radii on an exploration split, allowing a compact set around the dominant mass while a separate calibration split maintains marginal coverage.

01 Explore

Draw conditional samples and rank each draw by average distance to its four nearest neighbors.

02 Optimize

Use exploration responses to allocate radii by rank, minimizing a sum-of-ball-volumes proxy under an empirical coverage constraint.

03 Calibrate

On an independent calibration split, find one multiplier for the learned radius vector.

Method, data generation, and all four replicates

Data generation. For each response, draw a fresh independent set of 30 generated points from the same mixture. Rank by the mean distance to four nearest generated neighbors. This fixed-input, correctly specified generator is an illustrative stress test chosen to reveal allocation effects, not a paper benchmark or a claim of universal improvement.

Optimization. For each rank, use 15 radius candidates (a 0.005 floor plus 14 exploration-distance quantiles). Solve the resulting binary MILP offline with a 2% relative MIP gap. Its objective is Σᵣ Qᵣᵈ, an additive ball-volume proxy that counts overlaps; it does not minimize exact union volume. The page does not present the paper’s full-candidate exact MILP or rerun its greedy algorithm.

Calibration. PCP uses the conformal quantile of the nearest-sample distance. ORCA uses Sᵢ = minᵣ Eᵢᵣ / Qᵣ and the same order-statistic rule for a common multiplier. Both use 1,000 independent calibration responses. Coverage uses a further 1,000 independent test responses; set size averages the first 250 test draws. 1D union length is exact. 2D union area is estimated on a 100×100 grid spanning each set.

Validity. Split-conformal marginal coverage requires exchangeable calibration and test instances and a radius direction learned independently of calibration. Test percentages fluctuate around 90%; they can fall below it in a finite run.
